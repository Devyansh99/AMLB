Survival Analysis Notebook: Simple Explanation

This notebook predicts when a delivery happens. It uses time-to-event modeling, not just a late or not-late label.

Main Idea

What is Survival Analysis here?

  • Duration: days from approval to delivery (or censor date).
  • Event: delivered (event_observed = 1).
  • Censored: not delivered yet by cutoff (event_observed = 0).
Order approved -> Track days -> Delivered or censored

Notebook Pipeline

1Load data
2Build duration and event
3Kaplan-Meier curves
4Cox model for drivers

How Censoring Works

flowchart LR A[Order Approved] --> B{Delivered by reference date?} B -->|Yes| C[Event = 1, end date = delivered date] B -->|No| D[Event = 0, end date = reference date]

Kaplan-Meier Curve Meaning

It shows probability that package is still not delivered by day t. Curve starts high and goes down as deliveries happen.

Distance Group Comparison

The notebook also draws two KM curves: short-distance vs long-distance. If long-distance curve stays higher, those orders remain undelivered longer.

Higher curve = slower delivery

Cox Proportional Hazards (Simple interpretation)

flowchart LR X[Features: distance, weight, price, freight, items, seller size, cross-state] --> M[Cox Model] M --> O[Hazard Ratio for each feature]
  • Hazard Ratio > 1: tends to speed up delivery.
  • Hazard Ratio < 1: tends to slow down delivery.
  • p-value < 0.05: statistically stronger evidence in this run.

Predicted Curves (Step 7)

Notebook creates two representative profiles (shorter route vs longer route) and predicts survival curves from Cox model.

Assumption Check (Optional)

Cox assumes proportional hazards. The notebook includes an optional diagnostic check to test this assumption.

If assumptions are violated, interpretation should be more careful.

Business Takeaway

  • Survival analysis answers timing risk, not just late or not-late.
  • Kaplan-Meier gives a day-by-day risk view of still-not-delivered orders.
  • Cox model shows which factors delay or accelerate delivery.
  • This helps SLA planning and earlier interventions for risky shipments.
