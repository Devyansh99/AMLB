Problem Context

Business Question We Are Solving

Main operational pain

  • Delayed deliveries do not always create angry reviews.
  • Not all bad reviews are logistics faults.
  • If Olist sends vouchers to everyone, cost explodes.
Goal: target the right delayed orders, at the right time, with minimum cost.

Model strategy

  • Clean label noise using NLP.
  • Estimate causal drivers.
  • Forecast timing with survival models.
  • Deploy with temporal split and ROI thresholding.
Causal Inference

What causal notebook proves

Design

  • Outcome: dissatisfied review score.
  • Treatment: long distance shipment.
  • Confounders: product and seller characteristics.

DAG assumptions

flowchart LR C[Weight Price Freight Seller Region] --> T[Long Distance] C --> Y[Dissatisfaction] T --> Y

Methods used

  • Backdoor linear regression.
  • Propensity score matching.
  • Refuters and sensitivity analysis for credibility.
Causal Inference

How to present the result

Plain-language interpretation

  • After adjusting for observed confounders, long distance increases dissatisfaction risk.
  • Interpretation is in percentage-point effect, not absolute certainty.
  • Result is useful for prioritizing logistics mitigation on long routes.
ATE greater than zero means long distance causally raises bad-review probability on average.

Assumptions to state

  • No major unobserved confounder.
  • DAG direction is approximately correct.
  • Treated and untreated groups have overlap.
NLP Root Cause

Why NLP cleaning is mandatory

Problem

  • Many low-star reviews are product quality or wrong-item issues.
  • If treated as logistics failures, the model learns wrong patterns.

Approach

  • Zero-shot multilingual model on Portuguese review text.
  • Map predictions to business-friendly English categories.
  • Produce clean root-cause labels for pipeline use.
flowchart TD A[Low-score text reviews] --> B[Zero-shot multilingual NLP] B --> C[Logistics vs Product vs Service root cause] C --> D[Cleaner labels for model training]
NLP Root Cause

Business action layer from NLP output

Seller quality control

  • Track defective and wrong-product tags per seller.
  • Trigger warning, audit, or suspension thresholds.

Logistics optimization

  • Use logistics-tagged complaints for routing and SLA focus.
  • Avoid wasting logistics budget on non-logistics complaints.

Support escalation

  • Refund and service complaints routed to specialist teams.
  • Improves recovery speed and customer trust.
Cleaner labels lead to higher model reliability and better spending decisions.
Survival Analysis

Adding the time dimension

Core concepts

  • Duration: days from approval to delivery.
  • Event observed: delivered.
  • Censored: delivery not observed by reference date.

Methods

  • Kaplan-Meier curves for in-transit probability.
  • Cox PH model for hazard ratio interpretation.
HR above 1 means faster delivery, HR below 1 means slower delivery.

Censoring logic

flowchart LR A[Order approved] --> B{Delivered by reference date} B -->|Yes| C[Event = 1] B -->|No| D[Event = 0]
Survival Analysis

Operational value of survival outputs

Why this is stronger than late-or-not-late classification

  • Shows when risk accumulates over days, not only if delay exists.
  • Supports proactive messaging windows and SLA intervention timing.
  • Identifies factors with strongest delay acceleration or drag effects.

Decisions enabled

  • When to trigger customer updates.
  • Which orders need manual intervention.
  • Where to tighten process standards.
Temporal Deployment

Production simulation and model roles

Temporal split choice

  • Train: year 2017.
  • Test: H2 2018.
  • Purpose: mimic real-world deployment and avoid look-ahead effects.

Model A

  • Predicts delays from pre-shipment features.
  • Expected weak AUC without carrier route data.

Model B

  • Predicts anger risk among confirmed delayed orders.
  • This is the deployable decision model.
Temporal Deployment

ROI thresholding policy

Cost framework used in notebook

  • Voucher cost: R$15 per flagged order.
  • Bad-review penalty: R$50.
  • Voucher effectiveness assumption: 40 percent.
  • Threshold chosen to minimize total expected cost.
Total cost = voucher spend + missed bad-review cost - prevented bad-review value

Practical deployment loop

flowchart TD A[Carrier delay list at 9am] --> B[Score with Model B] B --> C[Apply threshold] C --> D[Send vouchers only to high-risk]

Final Summary

End-to-end decision recommendation

  • Use NLP to remove non-logistics complaint noise before modeling.
  • Use causal analysis to support why distance mitigation matters.
  • Use survival outputs for timing-sensitive interventions.
  • Use temporal deployment with Model B and ROI threshold as production policy.
