Temporal Analysis Notebook: Simple Visual Explanation

Main goal: For already delayed orders, predict which customers are likely to leave very bad reviews, so Olist can send proactive vouchers and reduce business loss.

Core Idea

Why this notebook uses two models

  • Model A: predict delay itself (hard, weak performance expected).
  • Model B: among delayed orders, predict angry customer risk (deployable model).
  • This is honest and practical: use carrier delay flag first, then run Model B.

Temporal split (production-like)

  • Train on 2017 orders.
  • Test on H2 2018 orders.
  • This avoids look-ahead leakage and mimics real deployment.
Past data -> train model -> apply on future orders

NLP root-cause block

  • Bad reviews are split into logistics vs product/seller issues.
  • This proves many bad reviews are not pure logistics failures.
  • So targeting delayed orders directly is more focused.

End-to-end pipeline

1Load merged data
2NLP root-cause cleanup
3Leakage-safe features
4Temporal split
5Train, ROI, causal, survival

Model logic diagram

flowchart LR A[All orders] --> B[Model A: Delay predictor] A --> C[Carrier confirms delay] C --> D[Model B: Anger risk among delayed] D --> E[Risk score and threshold] E --> F[Send R$15 voucher to high-risk only]

Feature engineering highlights

  • Distance, weight, price, freight ratio
  • Cross-state indicator
  • Seller experience signals
  • Interaction terms (distance x weight, distance x price)
Model A

Delay predictor summary

AUC around 0.55 to 0.58 is expected because carrier-level routing features are missing. This is documented transparently in the notebook.

Model B (Main)

Anger predictor summary

Applied only to confirmed late orders. This gives actionable triage for voucher policy and drives the business decision system.

ROI block (business decision engine)

  • Voucher cost: R$ 15
  • Bad review penalty: R$ 50
  • Voucher effectiveness: 40%
  • Find threshold that minimizes total cost
Total cost = voucher cost + missed bad-review cost - prevented bad-review value
Do Nothing Cost
Model B Deployed

Fridge insight

Heavy products shipped far get disproportionately worse reviews when delayed. This supports prioritized logistics mitigation for heavy-long routes.

Causal inference (IPW)

For delayed orders, estimate causal effect of far vs near shipment on bad-review probability, controlling confounders (weight, price, seasonality, seller effects).

Survival analysis

Adds timing view: who is angry and when delivery risk resolves. Kaplan-Meier and Cox PH explain factors slowing or speeding delivery.

Geo strategy

flowchart TD A[Angry and late order coordinates] --> B[KMeans clustering] B --> C[Proposed warehouse/DC locations] C --> D[Heatmap for logistics planning]

Final plain-English takeaway

  • Use carrier delay flag as trigger.
  • Run Model B to score anger risk and send vouchers only where needed.
  • This reduces avoidable penalty cost and improves customer experience.
  • Temporal split confirms performance is realistic for production timing.
Important: Model A alone is not enough for deployment. Model B + delay confirmation + thresholded ROI policy is the deployable system.
